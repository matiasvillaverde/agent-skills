# Public agent skills

- Read [README.md](README.md) and [PUBLISHING.md](PUBLISHING.md) before editing or publishing.
- Keep each workflow in `skills/<name>/SKILL.md`; move specialist detail into its references.
- Preserve upstream licenses and attribution. Keep private project and machine details out.
- Update the catalog and provenance when their owned content changes.
- Check links, skill metadata and the full publication diff; test changed executable behavior.
- No automatic tool installation, account configuration or publication from a skill invocation.
